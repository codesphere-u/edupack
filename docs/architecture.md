# Architecture — `edupack`

- `edupack.engine`: Structured Markdown question parser with SHA-256 pack fingerprinting, GSM-7 `<=160`-char SMS card formatter, zero-CDN offline HTML worksheet renderer, authentic SuperMemo SM-2 spaced-repetition scheduler, and SMS response parser + topic-mastery grader.
- `edupack.cli`: Offline teacher/hub CLI (`compile`, `demo`).
